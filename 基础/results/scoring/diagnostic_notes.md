# 诊断记录：改进方法是否依赖段落顺序或固定 ID

## 诊断目的
检查 starter/student.py 中的 improve(question, passages) 是否依据段落文本进行排序，而不是依赖固定段落 ID；同时检查输入顺序变化对排序结果的影响。

## 方法
使用三段合成资料，在相同问题下分别测试：
1. 原始输入顺序；
2. 反转输入顺序；
3. 将所有段落 ID 替换为同一个新 ID。

比较每种情况下排序后的段落文本序列。测试不调用模型 API，不修改正式实验日志。

## 观察结果
- 反转输入顺序后，排序文本序列一致：True。
- 更换段落 ID 后，排序文本序列一致：True。
- 在本次合成测试中，排序表现与按文本关键词重合度排序的实现一致。

## 解释与局限
结果支持该实现没有在这组测试中依赖固定段落 ID，且输入顺序变化没有改变排序文本序列。但这只是三段合成资料上的局部诊断，不能证明所有正式案例都具有相同表现，也不能证明该排序方法一定提高答案正确率或引用质量。

## 对正式实验结果的影响
本诊断不调用 API，不改变正式实验数据、模型配置或 student.py。正式实验结果保持原样。

## 诊断后的判断
暂时保留现有改进方法，并在报告中如实说明：该方法改变了段落顺序，但 R0 的 8 个配对案例中，基线与改进版的正确答案数量均为 7/8；不能据此声称正确率提升。
